Workflow — every two weeks

How to publish a new entry

Seven steps, no code. Start to finish takes about ten minutes once you've done it twice.

1

Open the generator

Open tools/new-post-generator.html in your browser — just double-click the file. No server, no install.

Open the generator →
2

Fill in the form

Title, category, a one-or-two-sentence meta description (the "dek"), tags, and image alt text.

Then paste your post text from the ODT file straight into the body box.

Only formatting rule: leave a blank line between paragraphs. That's how the tool knows where one paragraph ends and the next begins.
3

Click "Generate files"

The tool builds your slug automatically from the title (you can edit it), estimates the read time from your word count, and shows you the exact image filename it expects.

4

Upload the image

Rename your image file to match what the tool shows you (e.g. my-post-slug.jpg) and upload it to /assets/images/blog/ in GitHub.

GitHub → Add file → Upload files → drag it into that folder → commit.

5

Add the post page

Download the generated HTML file. In GitHub: Add file → Create new file → name it exactly blog/your-slug/index.html → paste the contents in → commit.

6

Update the entry list

Copy the JSON snippet the tool generated. Open blog/posts.json in GitHub, click the pencil (edit) icon, and paste the new entry into the array — remember the comma before it.

Set entry_no to one higher than whatever's currently the highest number in the file — the tool can't know this by itself since it runs entirely in your browser.
7

Done

No build step runs. GitHub Pages serves the new files within a minute or two of committing. Check kannan.ch/blog to confirm it showed up.

Quick checklist
  • Image uploaded to /assets/images/blog/[slug].[ext]
  • Post page committed at blog/[slug]/index.html
  • New entry added to posts.json, with a corrected entry_no
  • Blank line between every paragraph in the pasted text
  • Category matches one of the five: Technology, Process & Data, Work, Entrepreneurship, Humanity
